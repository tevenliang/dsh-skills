# 节操作

> WPS 文字文档 sections 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.sections.background_color`](sections.background_color.md) | 设置在线文字文档节的背景色 |
| [`wps.sections.border`](sections.border.md) | 删除在线文字文档节的页面边框 |
| [`wps.sections.border_art`](sections.border_art.md) | 设置在线文字文档节的页面边框艺术型 |
| [`wps.sections.border_data`](sections.border_data.md) | 查询在线文字文档节的边框数据 |
| [`wps.sections.border_distance`](sections.border_distance.md) | 设置在线文字文档节的页面边框距正文距离 |
| [`wps.sections.break`](sections.break.md) | 删除在线文字文档节的分节符 |
| [`wps.sections.columns`](sections.columns.md) | 删除在线文字文档节的分栏 |
| [`wps.sections.count`](sections.count.md) | 查询在线文字文档节的节数量 |
| [`wps.sections.grid_layout`](sections.grid_layout.md) | 设置在线文字文档节的网格排版 |
| [`wps.sections.gutter`](sections.gutter.md) | 设置在线文字文档节的装订线 |
| [`wps.sections.line_numbering`](sections.line_numbering.md) | 设置在线文字文档节的行号 |
| [`wps.sections.page_setup`](sections.page_setup.md) | 在线文字文档节的节页面设置：支持 查询/设置 |
