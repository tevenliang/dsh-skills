# 列表操作

| 工具 | 功能 |

| [`wps.lists.custom_bullet`](lists.custom_bullet.md) | 设置在线文字文档自定义项目符号 |

| [`wps.lists.multilevel`](lists.multilevel.md) | 对字符区间应用大纲多级列表模板 |
| [`wps.lists.number_format`](lists.number_format.md) | 为段落设置自定义编号格式 |
| [`wps.lists.remove`](lists.remove.md) | 移除在线文字文档范围列表格式 |
