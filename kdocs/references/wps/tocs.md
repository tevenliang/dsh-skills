# 目录操作

> WPS 文字文档 tocs 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.tocs.all`](tocs.all.md) | 删除在线文字文档全部目录 |
| [`wps.tocs.count`](tocs.count.md) | 查询在线文字文档目录数量 |
| [`wps.tocs.data`](tocs.data.md) | 查询、插入或删除在线文字文档目录 |
| [`wps.tocs.figures`](tocs.figures.md) | 插入在线文字文档图表目录 |
| [`wps.tocs.format`](tocs.format.md) | 设置在线文字文档目录的格式 |
| [`wps.tocs.update`](tocs.update.md) | 更新在线文字文档目录 |
| [`wps.tocs.update_all`](tocs.update_all.md) | 设置在线文字文档目录的全部目录 |
