# 域操作

> WPS 文字文档 fields 域相关操作。

| 工具 | 功能 |
|------|------|
| [`wps.fields.all`](fields.all.md) | 更新在线文字文档全部域 |
| [`wps.fields.by_paragraph`](fields.by_paragraph.md) | 插入在线文字文档域的段落插入域 |
| [`wps.fields.by_range`](fields.by_range.md) | 插入在线文字文档域的区间插入域 |
| [`wps.fields.count`](fields.count.md) | 查询在线文字文档域的域数量 |
| [`wps.fields.data`](fields.data.md) | 在线文字文档域的域数据：支持 删除/查询/设置 |
| [`wps.fields.list`](fields.list.md) | 查询在线文字文档域的域列表 |
| [`wps.fields.toggle_code`](fields.toggle_code.md) | 设置在线文字文档域的域代码 |
| [`wps.fields.unlink`](fields.unlink.md) | 设置在线文字文档域的域链接 |
