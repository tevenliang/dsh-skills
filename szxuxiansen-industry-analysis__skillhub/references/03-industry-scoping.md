# 行业界定与分类

## 双维度界定

- 横向：同一大类行业下各个平行细分行业之间的关系（决定颗粒度）。
- 纵向：同一大类行业中具有产业链联系的上下游环节。

研究前先明确自己要覆盖的细分行业与产业链环节范围，避免与他人研究口径分歧导致结论偏差。

## 分类标准

- 国内官方：《国民经济行业分类》（国家标准）、证监会《上市公司行业分类指引》。
- 投资常用：申万行业分类（一级 → 二级 → 三级，级数越高覆盖面越窄；同名不同层级用罗马数字后缀区分，如 农林牧渔 I/II）。
- 海外市场：GICS（全球行业分类系统）。
- 跨机构对比：同步对齐多家头部券商的行业分类规则，补全单一标准的盲区。

## 操作步骤

1. 确定分析目的（投资/战略/创业）与受众。
2. 选定分类标准与层级，匹配研究所需颗粒度。
3. 用横向 + 纵向两个维度界定研究边界。
4. 记录口径并在报告中注明，保证结论可比。

## 易错点

- 不注明口径导致结论不可比。
- 使用自定义分类造成认知偏差（优先采用市场通用分类标准）。
- 混淆同一名称在不同分类体系或不同层级中的含义。
