## 摘要与核心结论

- 一句话核心观点（结论先行，回答 So what）。
- 投资价值判断：赔率（市场空间）× 概率（确定性）总评。
- 主要风险（3–5 条，每条附跟踪指标）。
- 关键数据速览表：市场规模、渗透率、集中度 CRn、增速、估值等。

## 1. 行业界定与口径

- 横向细分行业 / 纵向产业链环节边界。
- 分类标准与颗粒度（《国民经济行业分类》/申万/GICS）。
- 数据口径与来源说明。

## 2. 产业生命周期定位

- 渗透率数值与阈值对照（15–20% 成长期、35–40% 成熟期）。
- 所处阶段结论与对应研究重点。
- 佐证：五类用户分布、销量/营收增速、政策目标。

## 3. 商业模式分析

- 商业模式画布（九维度表格）。
- 销售可行性：时间对标 / 空间对标 / 需求频次 × 弹性。
- 利润可行性：成本标准化程度 + UE 单位经济模型（单店/单客）测算。
- 商业模式的不确定性或演变可能。

## 4. 市场规模测算

- TAM / SAM / SOM 与渗透率、市场份额。
- 测算方法（需求导向 / 供给导向 / 供需匹配）与公式展示。
- 关键假设与敏感性（细颗粒度拆分、假设来源）。

## 5. 竞争格局与护城河

- 横向：市占率、CRn、市场结构四分类、集中度趋势（宏观/政策/生命周期/成熟市场对标）。
- 纵向：产业链利润分配、议价意愿 × 议价能力、各环节毛利率、占用上下游资金。
- 护城河：独占生产要素 + 独占生产关系。
- 产能/库存周期位置与拐点信号（龙头扩产/减产、价格战、出清）。

## 6. 外部环境（PEST）

- 政治 / 经济 / 社会文化 / 技术四维度，每项注明影响机制与方向。

## 7. 景气度与估值（投资场景）

- 景气度指标体系：前瞻指标 + 高频同步指标（量/价维度），数据频率与来源。
- 生命周期对应估值方法与估值区间。
- 相对估值（行业 PE ÷ 全 A PE）、交易拥挤度、货币政策与风险偏好。

## 8. 投资价值与风险

- 赔率 × 概率矩阵定位。
- 主要风险与需要持续跟踪的指标（何时修正判断）。
- 结论与落地建议：投 / 不投 / 观察（或战略进入 / 回避 / 观望）。
