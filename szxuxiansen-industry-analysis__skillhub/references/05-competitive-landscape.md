# 竞争格局与护城河

## 总体框架

竞争格局 = 横向（同行集中度）+ 纵向（产业链利润分配）。分析顺序：先看防守性（护城河），再看盈利性（竞争格局决定能否赚到钱）。

## 护城河：两类构建路径

### A. 独占生产要素（资源垄断）

- 劳动力：稀缺劳动力长期绑定（艺人、网红、明星讲师等，签长期合同 + 高额违约金）。
- 土地：独占附带资源禀赋的土地（矿产、特殊气候、独特微生物环境、位置优势；例：戴比尔斯曾控制全球 90% 钻石产量）。
- 资本：资本马太效应（有钱人抵押物更多、信用更好、融资成本更低；重资产行业洗牌期头部企业挤压中小玩家）。
- 技术：专利壁垒（科技/医药行业；类似版权之于内容、秘方之于中医）。
- 数据：专属标注数据规模（AI/大数据企业用独有数据训练出优于同行的模型）。

### B. 独占生产关系（网络效应/制度）

- 政府特许权：牌照、认证、许可（资本金门槛、经验高管等要求）。
- 渠道强绑定：经销商提前打款、派驻人员、合资成立区域销售公司。
- 行业标准联盟：牵头制定统一技术标准、申请地理标志保护，排除不达标产品。
- 高转换成本：社交关系、使用习惯、学习成本、数据沉淀、会员权益、长期合同。
- 独家供货协议：与稀缺资源供应商锁定长期独家供应。
- 品牌：长期广告投放/内容输出/品质管控积累，或资本收购成熟品牌。
- 双边平台：先集中资源把一端做到极致，再吸引另一端进驻。
- 精准渠道：按品类属性匹配渠道（即时性/体验型走线下、标准化重复消费走线上；大众品走大众商超、高端品走高端专柜，抢占黄金展示位）。

## 横向格局：行业集中度

关键指标：
- 市占率 = 公司销售额 ÷ 行业销售额（反映对上下游议价能力，不反映成本控制差异）。
- 行业集中度 CRn = 份额前 n 名企业市占率之和（n 常取 3/4/5/8）。

数据修正：万得、Choice 等终端的 CR4/CR8 只覆盖上市公司 → 用行业内所有上市公司营收合计 ÷ 测算的全行业市场规模，得到更贴近真实的集中度。

市场结构四分类（按 CR8）：分散竞争型、低集中竞争型、低集中寡占型、极高寡占型。

集中度趋势研判：
- 宏观经济：下行期集中度提升，上行期集中度下降。
- 政策：刺激需求的政策 → 集中度下降；限制供给的政策（供给侧改革、产能管控）→ 集中度上升。
- 生命周期：先降后升——导入期少数先行者集中度高，成长期涌入导致下降，成熟期兼并出清回升，衰退期维持高位。
- 成熟市场对标：参考欧美日韩对应行业成熟期 CRn 推断国内集中度天花板。

结论：集中度越高，龙头议价权与行业盈利越强；注意数据失真（大行业小公司，如餐饮，集中度指标意义有限）。

## 纵向格局：产业链利润分配

- 产业链 = 各产业部门基于技术经济联系形成的上下游链条，是商业模式在产业层面的映射，范围覆盖供应商的供应商、客户的客户。
- 利润流向识别：不必纠结各环节绝对收入占比，重点跟踪各环节终端收入占比的动态变化——占比持续提升的环节就是利润流入、景气向上的环节。
- 分配机制 = 议价意愿 × 议价能力：
  - 议价意愿两因子：① 商品/服务在下游的价值占比（占比低 → 下游对涨价容忍度高 → 议价意愿弱）；② 行业所处周期阶段（成长期让利抢份额，成熟期开源困难、议价意愿强）。
  - 议价能力：核心看对手方有没有得选——环节自身集中度 + 供需情况（供不应求、技术壁垒高的环节议价能力最强）。
- 判断指标：各环节毛利率（强势环节毛利率高）；占用上下游资金能力（应付账款、预收账款、合同负债）。
- 注意：环节整体赚得多 ≠ 环节内企业赚得多（还受环节内集中度影响）。

## 产能与库存周期（供给端拐点）

产能周期四阶段：供不应求（利用率高、利润好）→ 产能激增（玩家涌入、利润率下滑）→ 产能出清（弱势厂商退出、经营寒冬）→ 格局改善（利用率回升）。

产能扩张三阶段定性：龙头被动扩产（应对当下需求）→ 龙头主动扩产（看好长期）→ 行业外玩家无序涌入（接近周期顶部）；龙头主动缩减产能 ≈ 周期底部。

产能定量：净资本支出（购建固定资产等支付的现金 − 处置回收的现金净额）÷（折旧 + 摊销），比率 < 1.5 甚至跌破 1 时，行业大概率处于供给收缩底部。

库存周期四阶段：主动补库存、被动补库存（需求不及预期积压）、主动去库存、被动去库存（需求恢复、产量未跟上）。

库存系数（如汽车经销商）= 期末库存量 ÷ 当期销售量；合理 0.8–1.2，>1.5 警戒，>2.5 库存过高。

底部/顶部信号：底部——龙头减产、赛道玩家退出、分析师不推荐；顶部——龙头扩产、行业外玩家涌入、分析师跳空上调评级。

特殊机会信号：
- 龙头逆势扩张：需求下行仍扩产 → 行业远未到天花板，龙头强化规模优势（需核查低成本资金支持）。
- 龙头主动价格战：成长期需求没问题时主动降价 → 中小产能加速出清、集中度快速提升。
- 衰退期供给出清：供给收缩速度快于需求下降 → 产品价格逆势上涨，龙头受益（例：煤炭）。

## 易错点

- 直接使用未经修正的终端 CRn 数据。
- 只算集中度数值，不追踪其变化趋势与驱动因素。
- 把环节利润等同于环节内企业利润，忽略环节内集中度。
