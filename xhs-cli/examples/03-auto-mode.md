# 示例 03: auto 模式(一条龙,最常用)

## 场景

输入关键字,直接拿到 top N 条的完整正文+图片,无需手动复制 note_id/token。

## 命令

```bash
python3 ~/.agents/tianwenliang/.agents/skills/xhs-cli/scripts/xhs_search.py auto \
    "codex免费试用" --limit 2 --max-images 2 --render
```

## 实际输出结构

```markdown
## 🔍 搜索结果(共 2 条)

| # | 标题 | 作者 | 👍 | ⭐ | 💬 |
|---|---|---|---|---|---|
| 1 | ... | ... | ... | ... | ... |
| 2 | ... | ... | ... | ... | ... |

============================================================

--- 第 1/2 条 ---

## 📖 [笔记 1 标题]
[完整正文 + 图片]

--- 第 2/2 条 ---

## 📖 [笔记 2 标题]
[完整正文 + 图片]
```

## 为什么这个最常用

- **一次调用拿到全部信息**:不用 search 后再手动 detail
- **自动加 sleep**:每条 read 之间 sleep 3s,避免滑块验证码
- **自动下载图**:`--render` 默认开启
- **适用 Codex 场景**:Codex 调一次就能把结果完整展示

## 适用与不适用

| ✅ 适用 | ❌ 不适用 |
|---|---|
| 临时调研、关键字浏览 | 批量监控 watchlist(用 crawl) |
| Codex on-demand 调用 | 需要写 vault md 留底(用 crawl) |
| 1-5 条结果即可 | 需要 50+ 条(风控+性能) |

## 防风控参数

```bash
# 默认 sleep 3s,够稳
--sleep 3

# 想更快(可能有风控)
--sleep 1

# 想更稳(大 batch)
--sleep 8
```
