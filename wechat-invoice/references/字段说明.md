## Excel Sheet 结构

每个公司一个 `.xlsx` 文件，包含：
1. **「汇总」sheet**（默认打开的）— 跨月统计，含「全期合计」行
2. **每个有发票的月份一个 sheet** — 形如 `2026-06`、`2026-07`
3. 汇总 sheet 的「月份」列是超链接 → 跳到对应月份的 sheet

## 月份 sheet 列

| 列名 | 来源 | 含义 |
|------|------|------|
| 序号 | 自动 | 1-based 行号 |
| 开票日期 | PDF「开票日期」 | yyyy年mm月dd日 |
| 发票号码 | PDF「发票号码」 | 8/20 位数字 |
| 项目名称 | PDF「项目名称」 | `*类目*名称` 格式 |
| 数量 | PDF | 专用发票有，普通发票可能为空 |
| 单价 | PDF | 同上 |
| 金额(不含税) | PDF | 自动识别数值 |
| 税率 | PDF | 形如 `6%` |
| 税额 | PDF | 自动识别数值 |
| 价税合计(小写) | PDF | 自动识别数值 |
| 价税合计(大写) | PDF | 中文大写金额 |
| 销售方 | PDF「销 名称」 | 开票方 |
| 销售方税号 | PDF | 统一社会信用代码 |
| 购买方 | PDF「购 名称」 | 收票方 |
| 购买方税号 | PDF | 统一社会信用代码 |
| 备注 | PDF「备注」 | 包含开票人/收款人/复核人 |
| 源文件 | 文件名 | 超链接 → `../../invoices/{公司}/{月}/{文件}` |

## 合计行（月份 sheet 末尾）

末行「合计」使用 Excel `SUM()` 公式：
- 金额(不含税) → `=SUM(G3:Gn)`
- 税额 → `=SUM(I3:In)`
- 价税合计(小写) → `=SUM(J3:Jn)`

打开 Excel 后 LibreOffice/Excel 会自动计算。

## 汇总 sheet 列

| 列名 | 含义 |
|------|------|
| 月份 | YYYY-MM，超链接到对应 sheet |
| 发票张数 | 该月该公司的发票总数 |
| 金额(不含税)合计 | 该月不含税金额之和 |
| 税额合计 | 该月税额之和 |
| 价税合计(小写)合计 | 该月价税合计之和 |
| 备注 | 该月所有销售方（去重后拼接） |

末行「全期合计」— 所有月份的累计。

## 公司短名

`config.json` 中 `companies` 数组的 `key` 字段，用于 Excel 文件名；
`match` 字段用于在 PDF「购买方」名称中做子串匹配。

建议：
- 不带括号和特殊字符（`/`、空格等）
- 简短好认，例如「启智路演中」「跨维智能数字」

## 已知坑

1. **PDF 数量/单价列为空**：餐饮类普通发票在 PDF 中数量/单价列被压窄，文本提取为空。
   解析器会跳过这两列，仅返回金额/税率/税额。
2. **项目名被截断**：`*生产生活服务*信息技术服务` 这类名称可能跨两行（`信息技术` + `服务`）。
   解析器用「数据行 + 续行拼接」处理。
3. **加密 PDF**：微信附件中偶有非发票的加密 PDF（股票研报等）。
   解析器对加密文件返回 `{"错误": "..."}` 占位记录，build_excel 不会写入。
4. **签名图重复**：「备注」列中签名转文字会产生 `开票人：周薇 周薇`（周薇 重复）。
   原始签名只有一个，是 PDF 文本层冗余，不影响数据正确性。

## 复现命令

```bash
PY=/path/to/python/with/pdfplumber+openpyxl

# 复制 src 脚本到项目
cp -r /path/to/skill/scripts/* /path/to/project/scripts/

# 编辑 config.json
$PROJECT/config.json

# 一键跑全流程
$PY scripts/ingest.py --config config.json

# 仅重新生成 Excel（raw/ 已就位）
$PY scripts/ingest.py --config config.json --skip-copy
```
